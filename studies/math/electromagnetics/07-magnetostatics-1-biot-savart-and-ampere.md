## 핵심 요약

정자계는 시간에 따라 변하지 않는 전류가 만드는 자기장을 다룬다. 전하가 정지해 있을 때 전기장이 생기듯, 전하가 정상적으로 움직이면 자기장이 생긴다. 핵심 법칙은 로렌츠 힘, 비오-사바르 법칙, 앙페르 회로 법칙, 자기 벡터 포텐셜이다.

## 정자계의 출발점

정전계의 실험적 출발점이 쿨롱 법칙이라면, 정자계의 출발점은 전류가 흐르는 도선 사이에 힘이 작용한다는 실험 사실이다.

- Oersted: 전류가 흐르는 도선이 자기장을 만든다.
- Ampere: 전류가 흐르는 도선 사이에 힘이 작용한다.
- Biot-Savart: 정상 전류가 만드는 자기장을 적분 법칙으로 표현한다.

## 로렌츠 힘

전하 `q`가 전기장과 자기장 속에서 속도 `u`로 움직이면 받는 힘은

```text
F = q(E + u × B)
```

이다. 전기력 `qE`는 입자의 운동에너지를 바꿀 수 있지만, 자기력 `q u × B`는 속도에 수직이므로 일을 하지 않는다. 자기력은 입자의 속력보다 방향을 바꾼다.

전류 요소가 받는 힘은

```text
dF = I dl × B
```

로 쓴다.

## 비오-사바르 법칙

전류 요소 `I dl`이 관측점에 만드는 미소 자기장은

```text
dB = (μ0 / 4π) (I dl × aR) / R^2
```

이고, 전체 자기장은 전류 경로 전체에 대해 적분한다.

```text
B = ∫C (μ0 / 4π) (I dl × aR) / R^2
```

부피 전류밀도 `J`로 표현하면

```text
B = ∫V (μ0 / 4π) (J(r') × aR) / R^2 dV'
```

이는 정전계에서 Coulomb 법칙과 중첩 원리로 전기장을 구하는 방식과 대응된다.

## 정자계의 기본 방정식

자유공간 정자계에서 중요한 두 식은 다음이다.

```text
∇ · B = 0
∇ × B = μ0 J
```

첫 식은 자기 단극자가 없다는 뜻이다. 자기장 선은 시작점과 끝점 없이 닫힌 선을 이룬다. 둘째 식은 전류가 자기장의 회전을 만든다는 뜻이다.

## 앙페르 회로 법칙

비오-사바르 법칙은 항상 쓸 수 있지만 적분이 복잡할 수 있다. 대칭성이 강한 경우에는 앙페르 회로 법칙이 훨씬 빠르다.

```text
∮C B · dl = μ0 Ienclosed
```

또는 자유공간이 아닌 매질을 포함하면 `H`를 사용해

```text
∮C H · dl = Ifree,enclosed
```

로 쓴다.

## 대표 대칭 문제

### 무한 직선 도선

반지름 `r`인 원형 앙페르 경로를 잡으면 자기장은 원주 방향이고 크기는 일정하다.

```text
B = μ0 I / (2πr) aφ
```

### 균일 전류가 흐르는 원통 도선

도선 내부에서는 포함 전류가 `r^2`에 비례하므로 `B`가 `r`에 비례한다. 외부에서는 전체 전류 `I`를 포함하므로 `1/r`로 감소한다.

### 긴 솔레노이드

긴 솔레노이드 내부에서는 자기장이 거의 균일하고 외부장은 작다고 근사한다.

```text
B = μ0 (N/l) I az
```

### 무한 전류 시트

표면 전류밀도 `Js`가 흐르는 무한 평면의 양쪽에는 크기가 같은 자기장이 생기며 방향은 서로 반대이다.

```text
B = μ0 Js / 2
```

## 자기 벡터 포텐셜

`∇ · B = 0`이므로 자기장은 어떤 벡터 포텐셜의 curl로 쓸 수 있다.

```text
B = ∇ × A
```

`A`는 유일하지 않다. `A' = A + ∇ψ`도 같은 `B`를 만든다. 계산을 단순하게 하기 위해 Coulomb gauge

```text
∇ · A = 0
```

를 선택할 수 있다. 이때 정자계에서는 벡터 포아송 방정식이 나온다.

```text
∇²A = -μ0 J
```

## 자기 쌍극자

작은 전류 루프는 멀리서 자기 쌍극자처럼 보인다. 자기 쌍극자 모멘트는

```text
m = I S an
```

으로 정의한다. 균일 자기장 속 전류 루프는 순힘은 0일 수 있지만 토크를 받아 회전하려 한다.

```text
T = m × B
```

전동기는 이 토크를 이용하되, 계속 같은 방향으로 회전하려면 전류 방향을 적절히 바꾸어야 한다.

## 보강 학습 노트

### 큰 그림

- 이 문서는 **07. 정자계 I - 비오-사바르와 앙페르 법칙**를 다루며, 벡터해석을 바탕으로 전기장, 자기장, 물질 경계조건, Maxwell 방정식을 연결해 전자기 현상을 설명한다.
- 단편적인 정의를 외우기보다 입력이 무엇이고, 내부에서 어떤 변환이 일어나며, 출력이나 성능 지표가 어떻게 결정되는지 흐름으로 잡는 것이 좋다.
- 앞뒤 단원과 연결해 보면 이 주제가 왜 필요한지, 어떤 가정을 추가하거나 완화하는지 더 분명해진다.

### 핵심을 더 깊게 보기

- 전자기학 문제는 대칭성과 좌표계를 먼저 정하면 적분 경로와 면을 자연스럽게 고를 수 있다.
- 경계조건은 normal/tangential 성분을 나누고 free source 존재 여부를 따져 적용한다.
- 전자기학은 field의 미분형/적분형 표현을 상황에 맞게 바꾸는 능력이 핵심이다.
- 대칭성이 강한 문제는 Coulomb/Biot-Savart 적분보다 Gauss/Ampere 법칙이 훨씬 간단하다.
- 경계조건은 Maxwell 방정식을 작은 pillbox/loop에 적용한 결과이며 물질 상수가 field 분포를 바꾼다.

### 문제 풀이 또는 구현 루틴

- 좌표계를 먼저 고르고 대칭성으로 field 방향과 변수 의존성을 줄인다.
- 미분형과 적분형 중 어떤 형태가 더 쉬운지 판단한 뒤 법칙을 적용한다.
- 경계에서는 normal/tangential component를 나누고 free charge/current 존재 여부를 표시한다.
- 마지막에는 단위, 차원, boundary condition, edge case를 확인해 계산 결과가 현실적인지 검산한다.

### 자주 하는 실수

- 벡터 방향을 scalar 크기처럼 계산하면 부호와 성분이 쉽게 틀린다.
- 전위와 전기장은 음의 gradient 관계이므로 증가 방향을 혼동하지 않는다.
- 시간 변화장이 있으면 electrostatics/magnetostatics에서 쓰던 보존장 가정이 깨질 수 있다.
- 정의를 그대로 적용하기 전에 이 단원에서 전제한 ideal assumption이 실제 문제에서도 유지되는지 확인한다.
