## 디지털 설계 학습 지도

- Digital Logic Circuits는 논리와 FSM의 이론 기반이고, Basic Digital Lab은 이를 FPGA/SoC 보드 위에서 검증하는 실습 축이다.
- Verilog 코드는 software처럼 순차 실행되는 명령 목록이 아니라 hardware 구조와 clocked state를 기술한다는 점을 의식한다.
- 실습 문서는 simulation, synthesis, constraints, bitstream, board debug를 같은 순서로 점검하면 재현성이 좋아진다.
- 각 하위 노트는 빠른 요약으로 시작해 세부 설명으로 내려가도록 읽고, 마지막에는 직접 설명할 수 있는 질문을 하나 이상 남긴다.

## 복습 루틴

- 1회독: 제목과 목차를 훑으며 이 과목이 다루는 대상과 추상화 층을 잡는다.
- 2회독: 각 노트의 핵심 식, 회로, 알고리즘, 시스템 흐름을 손으로 다시 써 본다.
- 3회독: 예제나 과제 문서를 기준으로 입력 조건을 바꾸었을 때 결과가 어떻게 달라지는지 스스로 질문한다.
- 시험 직전: 자주 하는 실수와 점검 질문만 모아 빠르게 훑고, 설명이 막히는 노트로 되돌아간다.
