## 아키텍처 계열 학습 지도

- Computer Architecture는 ISA와 datapath, Microprocessor는 ARM/SSD와 I/O, Intelligent System Design은 FPGA/SoC 구현으로 초점이 다르다.
- 성능은 instruction count, CPI, clock, memory hierarchy, bus/IO latency 중 무엇이 병목인지 분해한다.
- NPU 주제는 연산량보다 data movement와 quantization을 중심에 두면 다른 가속기 과목과 자연스럽게 연결된다.
- 각 하위 노트는 빠른 요약으로 시작해 세부 설명으로 내려가도록 읽고, 마지막에는 직접 설명할 수 있는 질문을 하나 이상 남긴다.

## 복습 루틴

- 1회독: 제목과 목차를 훑으며 이 과목이 다루는 대상과 추상화 층을 잡는다.
- 2회독: 각 노트의 핵심 식, 회로, 알고리즘, 시스템 흐름을 손으로 다시 써 본다.
- 3회독: 예제나 과제 문서를 기준으로 입력 조건을 바꾸었을 때 결과가 어떻게 달라지는지 스스로 질문한다.
- 시험 직전: 자주 하는 실수와 점검 질문만 모아 빠르게 훑고, 설명이 막히는 노트로 되돌아간다.
