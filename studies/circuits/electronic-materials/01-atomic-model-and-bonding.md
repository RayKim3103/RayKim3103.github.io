## 개요

전자재료의 전기·광학적 성질은 **원자 구조 → 전자 에너지 준위 → 결합 방식**에서 출발한다.

```text
Dalton/Thomson/Rutherford/Bohr/Schrödinger 모형 → 양자수 → Pauli/Hund
→ 1차 결합(이온·공유·금속) + 2차 결합(van der Waals·수소)
→ 결합에너지 ↔ 녹는점·탄성률·열팽창
```

---

## 1. 원자 모형의 발전

| 모형 | 핵심 | 한계 |
|---|---|---|
| **Dalton** | 물질 = 쪼갤 수 없는 원자의 조합 | 내부 구조 없음 |
| **Thomson** | 전자 발견, plum pudding | 핵 개념 없음 |
| **Rutherford** | α 산란 → 작고 무거운 **양전하 핵** + 빈 공간 | 가속 전자가 EM파 방출 → 원자 불안정 |
| **Bohr** | 특정 반지름·에너지의 **안정 궤도**, 각운동량 양자화 | 다전자 원자·미세구조 설명 못 함 |
| **Schrödinger** | 전자 = 파동함수 확률분포 | (현대 표준) |

## 2. Bohr 모형

**세 가지 가정**:
1. 전자는 특정 안정 궤도에만 존재
2. 궤도 각운동량 양자화: $$L_n = mvr = n\dfrac{h}{2\pi} = n\hbar$$
3. 준위 차이만큼 에너지를 흡수/방출하며 궤도 전이

$$
E_n = -\frac{13.6}{n^2}\,\text{eV}, \qquad \Delta E = E_m - E_n = h\nu
$$

(반지름 $$r_n = n^2 a_0$$, $$a_0 = 0.0529\,\text{nm}$$ = Bohr 반지름.)

**수소 선 스펙트럼**:

| series | 종착 준위 | 영역 |
|---|---|---|
| Lyman | $$n = 1$$ | 자외선 |
| Balmer | $$n = 2$$ | 가시광 |
| Paschen | $$n = 3$$ | 적외선 |

불연속 선 스펙트럼 = 에너지 준위가 **양자화**되어 있다는 직접 증거.

## 3. 밴드 이론 기본 용어

| 기호 | 의미 |
|---|---|
| $$E_{vac}$$ | 진공 준위 — 전자가 고체를 완전히 벗어난 기준 |
| $$E_C$$ | 전도대 바닥 — 자유 이동·전류 기여 가능 |
| $$E_V$$ | 가전자대 꼭대기 — 결합 전자가 채움 |
| $$E_F$$ | 페르미 준위 — 점유 확률 기준(화학 퍼텐셜) |
| $$\chi$$ | 전자친화도 = $$E_{vac} - E_C$$ |
| $$\Phi$$ (work function) | $$E_{vac} - E_F$$ (금속에서 $$E_F$$ 전자를 진공으로) |
| $$E_g$$ | 금지대역 = $$E_C - E_V$$ |
| 이온화 에너지 | $$E_{vac} - E_V$$ |

## 4. 양자수와 전자 배치

| 양자수 | 의미 | 값 |
|---|---|---|
| $$n$$ | 주양자수 (에너지·껍질 K/L/M/N) | 1, 2, 3, … |
| $$l$$ | 궤도각운동량 (부껍질 s/p/d/f) | 0 … $$n-1$$ |
| $$m_l$$ | 자기 양자수 | $$-l$$ … $$+l$$ |
| $$m_s$$ | 스핀 | $$\pm\tfrac12$$ |

- **Pauli 배타 원리**: 한 원자에서 두 전자의 네 양자수가 모두 같을 수 없다 → 각 궤도에 스핀 반대 전자 2개.
- **Hund 규칙**: 같은 부껍질의 여러 궤도에 먼저 같은 스핀 전자를 하나씩 채운 뒤 짝짓기 → 전이금속 d 부껍질 특성, 자성.

## 5. 화학 결합 — 에너지 관점

두 원자가 가까워지면 인력·반발력이 경쟁 → 순힘 0인 거리 $$r_0$$에서 포텐셜 에너지 최소:
$$
\left.\frac{dE}{dr}\right|_{r_0} = 0
$$
결합 에너지가 클수록 원자를 떼기 어렵고 **녹는점·탄성률**이 크다.

### 1차 결합

| 결합 | 근원 | 방향성 | 예 |
|---|---|---|---|
| **이온** | 양이온↔음이온 Coulomb 인력 | 약함 (전방향) | NaCl |
| **공유** | 원자가전자 공유 → 핵–공유전자 인력 | 강함 (사면체 등) | H₂, CH₄, diamond, Si |
| **금속** | 양이온 격자 + 비국소화 전자기체 | 없음 | Cu, Fe |

밴드 관점: 금속은 **부분적으로 찬 밴드** → 작은 전기장에도 전자 상태 변화 → 높은 전기·열전도.

### 2차 결합

| 결합 | 근원 | 세기 |
|---|---|---|
| **van der Waals** | 순간 쌍극자 → 유도 쌍극자 (London 분산력) | 2차 중 가장 약함, 분자량↑ → 분극↑ → 세짐 |
| **수소** | H가 F/O/N(전기음성도 큼)과 결합 후 다른 전기음성 원자와 상호작용 | 2차 중 강함 — 물의 높은 끓는점 |

## 6. 기계·열적 성질 연결

### Young's modulus
$$
E_{Young} = \frac{\text{stress}}{\text{strain}} \quad [\text{N/m}^2]
$$
결합이 강하고 포텐셜 곡선이 가파를수록 같은 힘에 변형이 작아 탄성률 ↑.

### 열팽창
$$
L = L_0\,[1 + \lambda(T - T_0)]
$$
포텐셜 에너지 곡선이 **비대칭**(반발 쪽이 더 가파름)이라 진동 진폭이 커질수록 평균 원자 간 거리가 먼 쪽으로 이동 → $$\lambda$$ (선팽창계수).

### 에너지 분포와 열평형
- **Maxwell–Boltzmann 분포**: 온도에 따른 분자 속도/에너지 분포.
- 활성화 에너지 $$E_A$$를 넘는 입자 비율 $$\propto e^{-E_A/kT}$$ → 온도 ↑ 시 장벽 넘는 입자 급증 (Arrhenius).
- 열평형 = 장시간 평균으로 두 물체 간 순 에너지 전달 0.
